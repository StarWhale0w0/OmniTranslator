# 📚 OmniTranslator Pro v1.1.0

OmniTranslator Pro는 Google Gemini AI 기반의 장편 소설(Light Novel / Web Novel) 및 전자책 전문 고성능 배치 번역 데스크톱 애플리케이션입니다.

EPUB과 TXT 문서를 완벽 지원하며, 다중 API 키 로테이션, 지능형 용어집 시스템, 그리고 실시간 대화 톤 보정 및 다중 품질 검사 엔진을 통해 빠르고 자연스러운 고품질 번역을 제공합니다.

---

## 🌟 주요 핵심 기능 (Key Features)

### 1. 📚 전자책(EPUB) 및 텍스트(TXT) 포맷 맞춤형 번역

* **EPUB DOM 구조 100% 보존:** HTML 태그(`<p>`, `<span>`, `<ruby>`, `<img>` 등), 삽화, CSS 스타일을 완벽 유지하며 본문 텍스트만 정밀 번역
* **📖 전자책 목차(TOC) 한국어 자동 동기화:** 번역 완료 시 챕터 제목을 자동 매핑하여 `toc.ncx` 및 `nav.xhtml` 목차를 100% 한국어로 갱신 및 패키징
* **TXT 순수 텍스트 번역:** 불필요한 HTML 가상 태그를 배제하고 자연스러운 문단 구조의 순수 텍스트(`.txt`)로 출력 및 저장
* **다중 인코딩 자동 판별:** `UTF-8`, `CP949`, `EUC-KR`, `UTF-16` 등 다양한 인코딩의 텍스트 파일을 깨짐 없이 자동 감지 및 로드

### 2. 🎭 웹소설 맞춤형 구어체 & 대화 톤 전담 엔진 (DialogueToneCorrector)

* **자연스러운 대화체 확립:** 또래, 친구, 청소년 간 대화에서 딱딱한 극존칭(`~하지 않습니까?`, `~그렇습니다`)을 배제하고 몰입감 높은 웹소설 구어체 반말(`~야?`, `~거든`, `~잖아`, `~했어`) 자동 적용
* **부자연스러운 사극체 정제:** 일반 인물 대화에서 뜬금없이 튀어나오는 고풍스러운 하오체(`~하오`, `~소이다`, `내리시오` 등)를 정제하고, 초월자/신격 등 특수 캐릭터의 위엄 있는 대사만 선별 허용
* **서술문-대화문 분리 보호:** 따옴표(`“ ”`, `" "`, `「 」`, `『 』`) 내부의 종결 어미만 정밀 타깃팅하여 본문 묘사 왜곡 없이 대사 어투만 완벽 보정

### 3. 🌐 언어별 특화 번역 프로필 & 일반명사 오역 방지 3중망

* 🇨🇳 **중국어 (ZH):**
* **광고 사이트 문구 자동 제거:** 웹소설/선협/무협 고유명사 한자 음독 반영, 서술형 과거 시제(~였다) 강제 적용 및 불필요한 사이트 광고 문구 자동 제거 
* **화폐/일반명사 오역 원천 차단:** 화폐 `钱(qián)`이 성씨/인명 '첸'으로 오역되는 문제를 프롬프트 + 추출기 + 후처리기 3중망으로 방어하여 '돈/푼/은자'로 정확히 번역
* **사물/단위 고유어 번역 강제:** 무기(`刀/剑/枪`), 이동수단(`车/船`), 기호품(`酒/茶/肉`) 등의 무분별한 병음 음역 방지
* **문맥 중심 호흡:** '그는/그녀는' 직역 남발 억제 및 한국어식 주어 생략/전환


* 🇯🇵 **일본어 (JA):** 라이트노벨 특유의 어조, 1인칭 대명사(`私`/`僕`/`俺`), 감정선 및 구어체 뉘앙스 최적화
* 🇺🇸 **영어 (EN):** 복합 관계절 문장 재구성 및 자연스러운 한국어 문체 전환

### 4. 🧠 맵-리듀스(Map-Reduce) 기반 AI 전수 용어집 추출

* **소설 전체 전수 스캔:** 수십만 자 분량의 장편 소설 전체를 18,000자 블록으로 분할 분석하여 인명, 지명, 몬스터, 스킬, 단체명 등 고유명사를 빠짐없이 추출
* **일반명사 필터링:** 일반 사물, 단위, 보통명사가 인명으로 오인되어 등록되는 현상 차단
* **동적 용어집 주입 (Dynamic Injection):** 번역 진행 시 현재 청크에 등장하는 용어만 선별 주입하여 전체 번역의 일관성 유지

### 5. 🛡️ 품질 검사기(QualityChecker) 환각 자가 검증 & 실시간 복구

* **문장 분할 오탐지 방지 (Sentence Bloating Fix):** 중국어 특유의 긴 복문(쉼표 만연체)이 한국어 다문장으로 분할될 때, 글자 수 비율 기반 검증으로 전환하여 불필요한 번역 중단 방지
* **단어 반복 및 CJK 키워드 문맥 보호:** 원문의 짧은 핵심 단어(`脏弹` 등) 및 한국어 조사 결합 서술(`더티밤이`, `더티밤은`)을 환각 목록에서 제외하고 실제 무한 루프 도배 패턴만 정밀 차단
* **인명 풀이 한자 병기 보존:** 동음이의어 구분 및 인명 한자 풀이(`푸(覆)` vs `푸(富)`), 주문 등 원문 일치 한자 병기 시 정상 통과(`Pass`)
* **사고 과정(Thinking) 유출 방지:** 모델의 내부 자가 검증 텍스트(`*Final check*`, `<think>` 등) 원천 차단 및 정제

### 6. ⚡ 다중 API 키 자동 순환 & 병렬 비동기 처리

* **Multi-API Key Rotation:** 복수의 Gemini API 키를 등록하여 분당 요청 제한(RPM/TPM) 및 429 오류를 방지하며 자동 순환(Round-Robin/Failover)
* **스마트 세션 이어하기 (Checkpoint):** 작업 중단 시 진행된 번역 청크와 용어집을 자동 보존하여 언제든 중단된 지점부터 이어서 번역 가능

### 7. 🎨 현대적인 PySide6 다크 테마 대시보드

* **헤더 상태 연동:** 상단 헤더에 현재 선택된 번역 언어 뱃지 실시간 표시
* **듀얼 프리뷰 패널:** 원문과 번역문을 나란히 비교할 수 있는 실시간 뷰어 제공
* **대시보드 모니터링:** 작업 진행률(%), 잔여 시간(ETA), 처리 속도(Chunks/sec) 및 상세 로그 콘솔 제공

## 🛠️ 기술 스택 (Tech Stack)

* **GUI Framework:** Python 3.12, PySide6 (Qt for Python), qasync
* **LLM Engine:** Google GenAI SDK (`gemini-2.5-flash`, `gemini-2.5-pro` 등)
* **Quality & Tone Processing:** QualityChecker v2, DialogueToneCorrector, GlossaryExtractor, TextCleaner
* **Document Processing:** ebooklib, BeautifulSoup4, lxml
* **Packaging:** PyInstaller (Standalone Windows Executable)

## 📥 설치 및 실행 방법

1. GitHub Releases에서 최신 버전의 `OmniTranslator_Pro_v1.1.0.zip` (또는 `.exe`)을 다운로드합니다.
2. 프로그램을 실행한 뒤 우측 상단 [⚙️ 설정]에서 발급받은 Gemini API Key를 1개 이상 입력합니다.
3. 원문 파일(`.epub` 또는 `.txt`)을 선택하고 **[🔍 AI 용어집 추출]** 또는 [▶ 번역 시작]을 클릭합니다.
