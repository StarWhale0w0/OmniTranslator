# 📚 OmniTranslator Pro v1.1.0

OmniTranslator Pro는 Google Gemini AI 기반의 장편 소설(Light Novel / Web Novel) 및 전자책 전문 고성능 비동기 배치 번역 데스크톱 애플리케이션입니다.

EPUB과 TXT 문서를 지원하며, 다중 API 키 로테이션, 지능형 용어집 시스템, 실시간 대화 톤 보정, 루비 태그 렌더링 정상화, 세션 무결성 검증망 및 2차 폴백 격리 아키텍처를 통해 장편 번역의 완주율과 번역 품질을 보장합니다.

---

## 🌟 주요 핵심 기능 (Key Features)

### 1. 📚 전자책(EPUB) 및 텍스트(TXT) 포맷 맞춤형 번역

* **루비 태그(`<ruby>`, `<rt>`) 지능형 평탄화 및 레이아웃 보호:**
* 일본어/중국어 라노벨 특유의 후리가나/독음 태그를 전처리 및 후처리에서 인라인으로 정제
* 단어 분절(`배<rt>어</rt>나오는` $\rightarrow$ `배어나오는`) 및 음절 복제형 말더듬(`세<rt>세</rt>계<rt>계</rt>` $\rightarrow$ `세계`) 현상을 스마트 중복 제거 병합(Overlap Deduplication) 알고리즘으로 해결
* EPUB 내부 CSS에 루비 인라인 리셋 스타일(`!important`)을 주입하여 한국어 전자책 뷰어에서의 행간 터짐 및 글자 들뜸 현상 차단


* **DOM-Aware 순수 텍스트 노드 분리 번역:** HTML 구조를 통째로 기계에 던지지 않고 `BeautifulSoup` DOM 트리에서 순수 텍스트 노드(`NavigableString`)만 추출하여 번역 후 1:1 재조립함으로써 서식 및 이미지 태그 손상률 0% 달성
* **다형성 태그 마스킹 복구 체계:** 번역기 왜곡으로 발생하는 고립 숫자 및 깨진 태그 파편(`27]`, `TAG_5]`, `[태그_N]`)을 태그 맵과 대조해 원래의 태그로 복원 및 잔여 찌꺼기 정제
* **전자책 목차(TOC) 한국어 자동 동기화 & UID 정합성:**
* 챕터 제목을 자동 매핑하여 `toc.ncx` 및 `nav.xhtml` 목차를 100% 한국어로 갱신
* EPUB 저장 전 `sanitize_book_uids`를 재귀 실행하여 `NoneType` item UID로 인한 빌드 에러 방지


* **TXT 순수 텍스트 번역 & 다중 인코딩 지원:** 가상 태그 없는 문단 중심 번역 지원 및 `UTF-8`, `CP949`, `EUC-KR`, `UTF-16` 자동 판별

### 2. 🎭 웹소설 맞춤형 구어체 & 대화 톤 전담 엔진 (DialogueToneCorrector)

* **자연스러운 대화체 확립:** 또래, 친구, 청소년 간 대화에서 딱딱한 극존칭(`~하지 않습니까?`, `~그렇습니다`)을 배제하고 몰입감 높은 웹소설 구어체 반말(`~야?`, `~거든`, `~잖아`, `~했어`) 자동 적용
* **부자연스러운 사극체 정제:** 일반 대화에서 튀어나오는 고풍스러운 하오체(`~하오`, `~소이다`, `내리시오` 등)를 정제하고, 초월자/신격 등 특수 캐릭터의 위엄 있는 대사만 선별 허용
* **서술문-대화문 분리 보호:** 따옴표(`“ ”`, `" "`, `「 」`, `『 』`) 내부의 종결 어미만 정밀 타깃팅하여 본문 서술 왜곡 없이 대사 어투만 보정
* **대화문 경계 보존 슬라이싱:** 청크 분할 시 마침표, 느낌표, 물음표뿐 아니라 닫는 따옴표(`」`, `』`, `"`) 경계를 엄격히 준수하여 대화 도중 문장이 잘려 지문과 엉키는 현상 방지

### 3. 🌐 언어별 특화 번역 프로필 & 일반명사 오역 방지 3중망

* 🇨🇳 **중국어 (ZH):**
* **광고 문구 자동 제거:** 웹소설/선협/무협 고유명사 한자 음독 반영, 서술형 과거 시제(~였다) 적용 및 텍스트 찌꺼기 자동 제거
* **화폐/일반명사 오역 원천 차단:** 화폐 `钱(qián)`이 성씨/인명 '첸'으로 오역되는 문제를 프롬프트 + 추출기 + 후처리기 3중망으로 방어하여 '돈/푼/은자'로 번역
* **사물/단위 고유어 번역 강제:** 무기(`刀/剑/枪`), 이동수단(`车/船`), 기호품(`酒/茶/肉`) 등의 무분별한 병음 음역 방지
* **문맥 중심 호흡:** '그는/그녀는' 직역 남발 억제 및 한국어식 주어 생략/전환


* 🇯🇵 **일본어 (JA):**
* **인명 한자음 직역 방지 엔진:** 일본식 신자체/상용 한자 인명(`将人`, `恋海`, `匠` 등)이 한국식 한자음('장인', '연해')으로 직역되는 것을 방지하고 올바른 인명('마사토', '코나미', '타쿠미')으로 일괄 교정
* **서브컬처 관용구 및 일상 어휘 복원:** `毛頭ない`(털끝만큼도 없다 $\rightarrow$ '마음은 털이 없어' 직역 방지), `さすがに`(유석에 방지), `目がバッテン`(눈이 뱅뱅 돌다), `盛り上がる`(분위기 띄우다) 등 관용구 정밀 매핑
* **일본 원작 중국어 중역본 특화 모드:** 중국식 병음 표기 규칙을 무효화하고 일본식 고유명사(지명/인명/관청) 및 엔화 단위를 원형 복원하는 중역본 전용 파이프라인 탑재


* 🇺🇸 **영어 (EN):** 복합 관계절 문장 재구성 및 자연스러운 한국어 문체 전환

### 4. 🧠 맵-리듀스(Map-Reduce) 기반 AI 전수 용어집 추출 & 격리

* **소설 전체 전수 스캔:** 장편 소설 전체를 18,000자 블록으로 분할 분석하여 인명, 지명, 몬스터, 스킬, 단체명 등 고유명사를 전수 추출
* **소설별 독립 용어집 격리 (`*.glossary.json`):** 작품 간 고유명사 충돌을 방지하기 위해 파일 단위로 용어집을 자동 분리·매핑
* **동적 용어집 주입 (Dynamic Injection):** 번역 진행 시 현재 청크에 등장하는 필수 용어만 선별 주입하여 문맥 길이 최적화 및 용어 일관성 유지

### 5. 🛡️ 세션 무결성 검증망 & 2차 폴백 격리 아키텍처

* **언어별 미번역 잔존 원천 차단 (`is_chunk_valid`):**
* **JA 세션:** 히라가나/가타카나가 3자 이상 검출되거나 한글 10자 미만 상태에서 일본어가 섞여 있으면 즉시 실패 처리
* **ZH 세션:** 한글 수 대비 비정상적 한자 다수 잔존(의도적 괄호 병기 제외) 및 번역 경고 주석 포함 청크 전면 거부
* **기계번역 오염 필터:** `유석에`, `후무후무`, `남자 사람`, `책장 낚시` 등 저급 기계번역 직역 찌꺼기 감지 시 자동 탈락


* **전 키 소진 감지 및 안전 일시정지 (Safe Pause):**
* Gemini API 키 전체가 429(할당량 소진) 쿨다운에 들어갈 경우, 저급 기계번역(GTX)으로 대체 저장하지 않고 파이프라인을 안전 일시정지(`self.pause()`)시켜 번역 오염 원천 차단
* 구글 번역 폴백은 30자 이하의 단순 UI/단문 스니펫 또는 사용자의 명시적 허용 시에만 제한적으로 동작


* **엄격한 완료 검증 (Strict Completion Check):** 전체 청크가 100% 완료되지 않은 중간 일시정지/오류 상태에서는 최종 EPUB 생성 및 체크포인트 정리를 중단하여 작업 진행 데이터 보존
* **원자적 디스크 동기화 & 자동 오염 정화 (Auto-Purge):**
* 체크포인트(`.meta.json`) 로드 시 기존 오염 청크를 자동 감지·제거한 후 원자적 쓰기(`_atomic_json_write` + `fsync`)로 디스크 즉시 동기화
* 재개 시 누락된 청크만 선별하여 AI 재번역 큐에 투입



### 6. ⚡ 다중 API 키 자동 순환 & 비동기 백그라운드 엔진

* **Multi-API Key Rotation & Cooldown:** 다중 Gemini API 키를 등록하여 분당 요청 제한(RPM) 및 429 오류 발생 시 지능형 쿨다운과 백오프를 거쳐 자동 순환
* **UI 프리징 방지 비동기 아키텍처:** 무거운 파일 I/O(EPUB 파싱/패키징, JSON 체크포인트 동기화)를 `run_in_executor`로 오프로딩하여 대용량 작업 중에도 UI 반응성 유지
* **리소스 안전 해제:** 애플리케이션 종료(`closeEvent`) 시 백그라운드 태스크 정리 및 잔여 체크포인트 디스크 플러시 보장

### 7. 🎨 현대적인 PySide6 다크 테마 대시보드

* **헤더 상태 연동:** 상단 헤더에 현재 선택된 번역 언어 뱃지 실시간 표시
* **듀얼 프리뷰 패널:** 원문과 번역문을 나란히 비교할 수 있는 실시간 뷰어 제공
* **대시보드 모니터링:** 작업 진행률(%), 잔여 시간(ETA), 처리 속도(Chunks/sec) 및 실시간 상세 로그 콘솔 제공

## 🛠️ 기술 스택 (Tech Stack)

* **GUI Framework:** Python 3.12, PySide6 (Qt for Python), qasync
* **LLM Engine:** Google GenAI SDK (`gemini-3.5-flash-lite`, `gemini-2.5-flash` 등)
* **Quality & Tone Processing:** QualityChecker v2, DialogueToneCorrector, GlossaryCorrector, GlossaryExtractor, TextCleaner
* **Document Processing:** ebooklib, BeautifulSoup4, lxml
* **Fallback & Network:** deep-translator, Google GTX direct endpoint, aiohttp
* **Packaging:** PyInstaller (Standalone Windows Executable)

## 📥 설치 및 실행 방법

1. GitHub Releases에서 최신 버전의 `OmniTranslator_Pro_v1.2.0.zip` (또는 `.exe`)을 다운로드합니다.
2. 프로그램을 실행한 뒤 우측 상단 [⚙️ 설정]에서 발급받은 Google Gemini API Key를 1개 이상 입력합니다.
* *Tip:* 무료 티어 사용 시 안정적인 대량 번역을 위해 모델을 `gemini-3.5-flash-lite`로 설정하고 요청 딜레이를 `1.0s` 내외로 지정하는 것을 권장합니다.


3. 원문 파일(`.epub` 또는 `.txt`)을 선택하고 [🔍 AI 용어집 추출]을 거친 후 [▶ 번역 시작]을 클릭합니다.
4. 작업 도중 API 쿼터가 소진되어 일시정지된 경우, 쿨다운 대기 후 [계속(Resume)]을 누르면 번역되지 않은 청크부터 안전하게 이어받아 완성합니다.
